## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install)

### Clone the repository

```bash
git clone https://github.com/Reyaanshs-Stuff/Reyaanshs-Things.git
cd Reyaanshs-Things
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```
